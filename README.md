## 01 — POSITION

Third Nature is a product practice focused on **software with identity**.

I work across creative development, full-stack systems, SaaS architecture, desktop products, motion, and interface design. The goal is not decoration around software — it is making the product, interaction, structure, and visual language feel like one system.

> **For Things That Don’t Exist Yet.**

## 04 — HOW I BUILD

<table>
<tr>
<td width="50%" valign="top">

### Product thinking
I start with the behavior of the product: what it should do, how it should feel, where friction exists, and what the user should understand without explanation.

### System structure
I map the logic underneath the surface — data, roles, APIs, workflows, states, boundaries, and how the product grows without becoming inconsistent.

</td>
<td width="50%" valign="top">

### Interaction language
Motion, hierarchy, transitions, spacing, and responsive behavior are treated as part of the product system rather than as finishing effects.

### Shipping discipline
I care about complete experiences: implementation, refinement, performance, edge cases, deployment, and the last 10% that makes something feel finished.

</td>
</tr>
</table>
