## About

I build digital products where **software, design, motion, and experimentation** meet.

Third Nature is where I develop immersive web experiences, SaaS products, desktop applications, and unconventional interfaces — with a focus on making ideas feel intentional, polished, and alive.

## What I Build

- **Creative web experiences** — cinematic interfaces, motion systems, immersive interaction, and non-traditional layouts.
- **Full-stack products** — modern applications, APIs, authentication, data flows, and production-ready architecture.
- **SaaS platforms** — multi-tenant systems, dashboards, workflows, role-based experiences, and scalable foundations.
- **Desktop products** — macOS, Windows, Swift, C#, and cross-platform product exploration.
