`Next.js` · `React` · `TypeScript` · `Tailwind CSS` · `Framer Motion` · `GSAP` · `Three.js`

[View Showcase](https://github.com/thirdnaturedev/casa-sombrero-showcase) · [Live Experience](https://casa-sombrero.vercel.app)
